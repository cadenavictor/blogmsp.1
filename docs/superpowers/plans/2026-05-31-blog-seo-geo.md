# Blog SEO/GEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Laravel 13 blog platform with closed admin, editorial CRUD, SEO/GEO metadata, AI crawler files, sitemap/feed generation, scripts management, and IndexNow support.

**Architecture:** Use server-rendered Blade for public and admin pages, Eloquent models for editorial content, and small service classes for SEO rendering, sitemap/feed generation, robots/llms output, and IndexNow submission. Keep controllers thin and test behavior through Laravel feature tests before adding implementation.

**Tech Stack:** Laravel 13, Blade, Vite/Tailwind, vanilla JavaScript, MySQL via Laragon, PHPUnit, Laravel HTTP client fake.

---
